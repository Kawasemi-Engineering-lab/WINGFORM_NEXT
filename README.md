# WINGFORM_NEXT

WINGFORM_NEXT is a Windows x64 tool for designing aircraft wings. Edit a planform, set airfoils and section positions, adjust height and bending, inspect the result in 3D, and export models for downstream use.

![WINGFORM_NEXT planform editor](images/WINGFORM_NEXT_plan.png)

## Download

**Version 0.3.6**

- [Japanese edition](https://github.com/Kawasemi-Engineering-lab/WINGFORM_NEXT/releases/download/v0.3.6/WINGFORM_NEXT_Windows_v0.3.6.zip)
- [English edition](https://github.com/Kawasemi-Engineering-lab/WINGFORM_NEXT/releases/download/v0.3.6/WINGFORM_NEXT_Windows_v0.3.6_EN.zip)

Extract the complete ZIP and launch `WINGFORM_NEXT.exe`. Python does not need to be installed.

## Features

- Edit wing outlines in plan view with straight segments and splines
- Set airfoils, section positions, rib angles, height, and bending
- Inspect the design in a 3D preview
- Export formats including STEP, STL, and Blender
